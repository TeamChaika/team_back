# Правила работы агента

## Навигация

Начни с [docs/PROJECT_MAP.md](docs/PROJECT_MAP.md): выбери модуль по задаче, затем проследи относящуюся к ней цепочку API → сервис → хранилище/интеграция. Для запуска, CI/CD и диагностики используй [операционную карту](docs/CODEMAPS/operations.md).

Это рабочий `TeamChaika/team_back`. Frontend — отдельный `TeamChaika/team_front` (локально обычно `../chaika-team-frontend`). Не путай рабочий код со старым `iiko_Collector/backend` или `iiko_Collector/service`.

При изменении маршрутов, модулей, схемы, источников данных или запуска обновляй соответствующую карту в той же задаче. Не расширяй права профилей и складов как побочный эффект. Не используй реальные накладные, платежи или Telegram-уведомления как тестовые данные.

## Оценка сложности и делегирование

Перед выполнением оценивай сложность задачи, учитывая неопределённость и последствия ошибки, а не только объём работы.

Используй субагентов для самостоятельных частей работы:

- лёгкие — `gpt-6-luna`;
- средние — `gpt-6-sol`;
- сложные — `gpt-6-astra`.

Если исполнитель не справляется, передавай работу модели следующего уровня вместе с полученными результатами, проверками и оставшимися проблемами: `gpt-6-luna` → `gpt-6-sol` → `gpt-6-astra`.

Коротко сообщай выбранную модель и причину. Для коротких ответов и простых неделимых действий не запускай лишних субагентов.
