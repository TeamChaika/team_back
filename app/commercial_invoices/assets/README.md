# Invoice fonts

`LiberationSans-Regular.ttf` and `LiberationSans-Bold.ttf` are unmodified
redistributable Liberation Sans font files, copied from the bundled
`pdfjs-dist/standard_fonts` runtime distribution. They include Cyrillic glyphs.
The SIL Open Font License 1.1 and copyright notices are retained verbatim in
`LICENSE_LIBERATION`. No operating-system proprietary fonts are required.
