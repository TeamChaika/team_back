# Помощник по закупкам через Timeweb

Чат использует существующие функции поиска товаров, истории поступлений и влияния цены на блюда. FastAPI проверяет права пользователя и выполняет расчёты по данным Supabase. Агент получает ограниченную выборку и формирует объяснение; ссылки на исходные документы формирует backend.

## Настройка агента

1. В Timeweb создайте приватного агента. Проверенная для подключения модель — GPT-5.4 Mini.
2. Задайте дневной лимит токенов. Для первого теста используется 50 000. Веб-поиск и базу знаний для этого сценария подключать не требуется.
3. Создайте отдельный API-ключ для сайта с правами на ИИ-сервисы. Ключ управления всей инфраструктурой в приложение не передавайте.
4. Скопируйте **Access ID** агента: это UUID из настроек API, а не числовой ID страницы агента.
5. Укажите переменные в backend-приложении Timeweb и выполните повторное развёртывание:

```dotenv
CHAIKA_AI_PROVIDER=timeweb
CHAIKA_AI_TIMEWEB_AGENT_ID=<Access ID агента в формате UUID>
CHAIKA_AI_API_KEY=<ключ доступа>
CHAIKA_AI_MODEL=gpt-5.4-mini
CHAIKA_AI_REQUESTS_PER_HOUR=20
CHAIKA_AI_MAX_OUTPUT_TOKENS=1800
```

Для локального запуска эти переменные можно сохранить в `.env.assistant`, исключённом из Git. Фронтенду ключ не нужен.

Модель выбирается в панели Timeweb. `CHAIKA_AI_MODEL` служит подписью в истории сайта: при смене модели агента обновите и эту переменную. Адрес провайдера фиксирован: `https://agent.timeweb.cloud/api/v1/cloud-ai/agents/{Access ID}/v1/chat/completions`.

## Проверка

После входа `/api/assistant/status` должен возвращать `configured: true` и `provider: timeweb`. Задайте в чате вопрос «Найди мясо бедро куриное и объясни изменение закупочной цены». У ответа должны появиться ссылки на закупочные цены и накладные. Перезагрузите страницу и проверьте сохранённую историю.

Успешный HTTP-ответ провайдера сам по себе не считается проверкой: backend сохраняет ответ только после хотя бы одного разрешённого обращения за данными. Неизвестные функции, некорректные параметры, изменившиеся права и незавершённые ответы отклоняются. Максимум — четыре вызова функций на один вопрос.

Если `configured: false`, проверьте ключ и Access ID. При ошибке авторизации ключ обновляется только в настройках backend. Лимиты провайдера и сбои отображаются в чате без содержимого ответа провайдера и секретов.
