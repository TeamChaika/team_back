# Архив заведений

Закрытие/сезонность задаётся администратором явно, независимо от отсутствия продаж
и выбора синхронизации. Архивирование не удаляет бизнес-данные, пользователей,
права, RMS-привязки и не включает/выключает обмен с iiko.

- `GET /api/management/venue-archives` возвращает `revision`, `archived_department_ids`,
  `departments: [{id,name}]`, `updated_at`.
- `POST /api/management/venue-archives` принимает `revision`, `archived_department_ids`.
  Требуются действующие административные права и существующая защита Origin.
  UUID проверяются по каталогу компании; дубликаты/неизвестные — 422,
  конфликт ревизии — 409. Сохранение проходит через транзакцию и аудит.
- Настройка хранится внутри прежнего `operation_settings.settings.analytics`.
  Старые строки без `analytics` означают пустой архив. Старый POST настроек
  синхронизации сохраняет архив, POST архива сохраняет обмен/склады. Оба используют
  одну ревизию. Новая миграция для дополнительного JSON-поля не требуется.
  Имя схемы берётся из `settings_schema(db)` (контекст компании).
- `/api/me` добавляет `archived` к разрешённым пользователю заведениям.
- `/api/overview?include_archived=true` включает архивные в разрешённую выборку.
  Без флага архив исключён из текущего и предыдущего периода, графиков и деталей.
  Явный выбор архивного без флага — 403. Отсутствие действующих — 403 с объяснением;
  пустая выборка никогда не превращается во «все».
- `GET /api/indicators/filters` принимает такой же query-флаг `include_archived`.
- `/api/indicators/query`, `/api/indicators/metric/{metric}` и варианты опций
  принимают `include_archived` в `IndicatorQuery` (по умолчанию false).
  Архивный режим не отменяет SyncPolicy: выключенные точки не запрашиваются у iiko;
  явный выбор выключенной точки по-прежнему возвращает 423. Сохранённая история
  «Обзора» доступна независимо от обмена.
- Ключи кэша показателей содержат ревизию настроек, эффективные заведения и флаг.
  Старые фоновые задания перепроверяют права/ревизию до и после запроса.
  Прогрев по умолчанию исключает архив, включая индивидуальные выборки.

Локальные проверки: `tests/test_venue_archive.py`, `test_operation_settings.py`,
`test_indicator_cache.py`, плюс существующие тесты Overview, Indicators и доступа.
Тесты PostgreSQL выполняются только в одноразовом локальном окружении.
Возврат из архива — сохранение массива без UUID заведения; перезагрузка истории
не требуется. Публикация и реальные изменения настроек выполняются отдельно.
